玖零六影视字幕生成工具 V1.4.2 — 配音识别修复
作者：陈冲

使用：完整解压到一个新文件夹，运行 906_SubtitleTool_V1.4.2.exe。
runtime 文件夹必须与主程序同级；不要与旧版 runtime 混合覆盖。
拖入配音和解说稿，选择一种输出格式，点击生成字幕。

本版只处理配音识别稳定性，不重做界面，不改原有字幕对齐与导出算法。
1. MP3、M4A、WAV 等输入均先转换为 16kHz 单声道 PCM WAV。
2. 程序在临时工作目录使用内部英文文件名，外部输入仍可使用中文路径、中文文件名。识别结束后清理临时配音和模型数据。
3. 识别器从与旧版相同的官方 whisper.cpp 固定提交重新构建，采用单一 CPU 静态构建，不再依赖 ggml 动态后端 DLL，也不调用显卡。
4. 中文识别模型从官方仓库获取，构建时和识别前校验 SHA256。
5. 失败时保存本地 906_subtitle_error.log；不会上传日志、音频或文稿。
6. 关闭窗口时终止正在运行的识别/转换进程，不建立后台服务或自动下载任务。
7. 主程序不调用 PowerShell；构建服务器使用 PowerShell 仅用于编译打包，不随软件运行。

验证范围：以随包测试报告为准。Windows 编译通过不等于真实项目全部验证通过，也不等于完成独立安全审计。
自动化语音回归使用上游公开 JFK 测试音频；不是用户项目录音。它验证 MP3/M4A 预处理、中文路径、实际识别、SRT 生成和子进程退出，不证明所有中文项目字幕都准确。
当前 FCPXML 与旧版 XML 仍沿用原实现；未进行 Mac Final Cut 实机导入验证。
老式 DOC 读取仍需要本机 Microsoft Word。TXT/DOCX 不需要安装 Word。
未进行数字签名或完整第三方安全审计。SHA256 用于校验文件一致性，不代表文件绝对安全。

出现错误时：查看程序同目录的 906_subtitle_error.log；同目录不可写时位于 %LOCALAPPDATA%\906SubtitleTool\logs。
发送日志前可检查是否包含本地路径信息。不要关闭杀毒保护，也不要将保密配音上传到公共检测网站。
